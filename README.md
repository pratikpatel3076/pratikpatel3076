## Featured Projects

### [RouteMind](https://github.com/pratikpatel3076/RouteMind)
**Last-mile delivery route optimization**

A route-planning platform that models delivery constraints and uses **Google OR-Tools** to solve vehicle-routing problems with time windows, vehicle capacity, and cash-on-delivery constraints. Includes a FastAPI backend, React/TypeScript interface, live updates, and an LLM layer that explains proposed route changes.

**Tech:** Python · FastAPI · OR-Tools · React · TypeScript · Supabase · WebSockets

### [VoiceBlast IVR](https://github.com/pratikpatel3076/voiceblast-ivr)
**Voice campaign and IVR management platform**

A web application for managing contact lists, audio uploads, outbound voice campaigns, and campaign reports. The project includes an Express API, MongoDB persistence, a React interface, and a simulation mode for testing campaign flows.

**Tech:** Node.js · Express · MongoDB · React · Twilio

### [Business Suite — AI HRMS](https://github.com/pratikpatel3076/Business-Suite---AI-HRMS)
**Modular business and HR management platform**

A modular ERP-style application bringing together HR management, employee operations, project workflows, and CRM capabilities. The repository documents implemented foundations alongside integrations and modules that are still planned.

**Tech:** FastAPI · React · TypeScript
